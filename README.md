## Featured Projects

### [RsyncGUI](https://github.com/kochj23/RsyncGUI) — File Sync
Professional rsync GUI for macOS with real-time progress, scheduled backups, and AI-powered insights. Modern replacement for the discontinued RsyncOSX.

### [MLXCode](https://github.com/kochj23/MLXCode) — Code Assistant
Local LLM-powered coding assistant using Apple MLX. Privacy-first alternative to GitHub Copilot — runs entirely on Apple Silicon with no cloud dependency.

### [MBox-Explorer](https://github.com/kochj23/MBox-Explorer) — Email Analysis
AI-powered MBOX email archive viewer with native RAG pipeline. Query emails in natural language using local models.

### [OneOnOne](https://github.com/kochj23/OneOnOne) — Meeting Manager
AI-assisted 1:1 meeting tracker for engineering managers. Agenda templates, action item tracking, and AI-generated summaries with iCloud sync.

### [Bastion](https://github.com/kochj23/Bastion) — Security Testing
AI-powered penetration testing platform for macOS. Network reconnaissance, vulnerability scanning, and intelligent exploit orchestration.

### [NMAPScanner](https://github.com/kochj23/NMAPScanner) — Network Security
macOS network scanner with HomeKit device discovery, vulnerability scanning, and comprehensive port detection.
